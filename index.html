Bienvenido a CineCloud

CineCloud es un sitio web sencillo desarrollado como práctica para implementar una aplicación web mediante servicios de computación en la nube.

El objetivo es demostrar cómo un sitio desarrollado localmente puede publicarse posteriormente en Railway para que pueda ser consultado desde Internet.
